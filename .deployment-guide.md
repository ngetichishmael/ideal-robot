# Quick Deployment Guide

## 🚀 Deploy After Making Changes

```bash
./deploy.sh
```

That's it! The script handles everything automatically.

## 📋 What the Script Does

1. **Cleans** previous build directory
2. **Builds** the project using Bun + Vite
3. **Backs up** current production version on server
4. **Deploys** new files to `/var/www/html/ts/atg/`
5. **Verifies** the site is responding correctly

## 🔧 Manual Steps (if needed)

```bash
# 1. Build
bun run build

# 2. Deploy
scp -r dist/* ishmael@84.247.183.99:/var/www/html/ts/atg/

# 3. Verify
curl -I https://atg.realsourcesafrica.com
```

## 🌐 Production Details

- **URL:** https://atg.realsourcesafrica.com
- **Server:** ishmael@84.247.183.99
- **Path:** /var/www/html/ts/atg/
- **Nginx Config:** /etc/nginx/sites-available/atg.realsourcesafrica.com

## 🔄 Typical Workflow

```bash
# 1. Make your changes in code
vim src/App.vue

# 2. Test locally
bun run dev

# 3. Deploy to production
./deploy.sh
```

## 📦 Backups

Backups are automatically created in `/tmp/atg-backups/` on the server with timestamp:
- Format: `atg-backup-YYYYMMDD-HHMMSS`

## ⚠️ Rollback (if needed)

```bash
# SSH to server
ssh ishmael@84.247.183.99

# List backups
ls -la /tmp/atg-backups/

# Restore from backup
sudo cp -r /tmp/atg-backups/atg-backup-YYYYMMDD-HHMMSS/* /var/www/html/ts/atg/
```
